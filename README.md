# 📈 COVID-19 & Malaysia Stock Market Analysis

Analyzed COVID-19 trends and their impact on Malaysia's KLSE stock market index using SQL for data analysis and Tableau for data visualization.

## 📊 Dashboard

![COVID-19 and its Impact on KLSE Index Price](images/covid-malaysia-dashboard.png)

## 🎯 Project Overview

This project explores the relationship between the COVID-19 pandemic and Malaysia's stock market performance. The analysis examines COVID-19 cases, deaths, vaccinations, and changes in the KLSE Index Price to identify trends throughout the pandemic.

## 🛠️ Tools Used

- **SQL Server** – Data cleaning, querying, and analysis
- **Tableau** – Data visualization and dashboard development
- **Our World in Data** – COVID-19 dataset
- **Yahoo Finance** – Historical KLSE Index data

## 🔍 Analysis

The dashboard examines:

- COVID-19 cases and deaths over time
- Growth in vaccinations during 2021
- Changes in daily COVID-19 cases
- Changes in the KLSE Index closing price
- How major periods of COVID-19 activity corresponded with stock market movements
